# RAGDOLL_SIM — Snow Physics

A realistic ragdoll sandbox in the browser (three.js + Rapier): a post-Soviet snow town with destructible terrain, realistic humans with an injury model, vehicles, weapons, weather and day/night.

**Play:** https://uhrichsam4.github.io/real-human/

Desktop Chrome or Safari with a decent GPU recommended. Click into the game to capture the mouse. Multiplayer: MULTIPLAYER → HOST, then COPY LINK and send it to a friend (peer-to-peer, up to 8 players; some strict networks may block it).

This repository contains only the built, playable game. Asset credits and licences are in [CREDITS.md](CREDITS.md); the human interior meshes are CC BY-SA 4.0 (derived from Z-Anatomy).
